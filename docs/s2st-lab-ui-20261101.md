# Experimental S2ST Lab in PersoDub Overdub (2026-11-01)

## Implemented user workflow

The S2ST Lab is an opt-in section in the existing **Export > Overdub**
dialog for a completed local dubbing project. It is NOT an alternative
default dubbing mode.

1. Expand "Experimental S2ST lab: English speech to Russian audio".
2. See 50 source diarization intervals per page, each with timestamps,
   speaker label and a playable **original** 16 kHz WAV preview.
3. Choose 1-6 intervals and confirm that each one contains speech only
   (no singing, hummed exercises or other protected vocal events).
4. Click Generate. The model runs in a separate Python process on Apple MPS.
   The UI polls persisted progress without freezing ordinary Overdub.
5. After completion, open Original WAV, Russian WAV and any eligible
   two-track MP4 with **Overdub** and **Original** audio streams.

No original input video, Qwen line WAV, SRT, approved event plan,
previous MP4 or user project status is replaced.

## Local configuration

The API reads explicit settings values through the existing
settings_env.current_value mechanism:

- PERSODUB_S2ST_PYTHON
- PERSODUB_S2ST_MODEL_DIR

If unset, the Mac research default is discovered under the current
user's ~/.persodub-dev-kit/research/seamless-m4t-v2/venv/bin/python
and ~/.persodub-dev-kit/models/seamless-m4t-v2-large.

These paths must point to the exact preinstalled offline model from the
prior experiment. The package contains code only, NOT the 9.24 GB
checkpoint shards. Models stay separate and this test workflow is not
commercially certified.

The S2ST runtime is isolated from normal PersoDub Python, which may be
different from Python 3.11 and does not need to import PyTorch/Transformers.

## API contracts

- GET /api/dub/jobs/{jid}/s2st?page=0 returns selected source revision
  token, bounded page of source cues, availability and latest run status.
- GET /api/dub/jobs/{jid}/s2st/source/{index}?source_token=...
  decodes a <=30s original audio cue on demand to 16 kHz mono PCM16 WAV,
  with a correct definite RIFF frame count and without source mutation.
- POST /api/dub/jobs/{jid}/s2st/start accepts strict integer source
  indices (1-6, distinct), the current source token and an explicit
  speech-review confirmation. It never accepts arbitrary file paths.
- GET /api/dub/jobs/{jid}/s2st/status polls the persisted worker
  status and progress and produces source/translation/video download URLs.
- GET /api/dub/jobs/{jid}/s2st/files/{run_id}/{name}
  serves only source-/ru- numbered WAVs and preview- numbered MP4
  from an actual saved experiment manifest. Reject arbitrary files.

The source token hashes the original cue manifest and the video's size and
modified-time. The worker separately hashes the actual source MP4 and each
extracted clip. Each experiment is stored inside its original project's
s2st-lab/{run-id}/data folder with source SHA and model SHA provenance.

Start is asynchronous; the heavy model runs with HF_HUB_OFFLINE=1,
TRANSFORMERS_OFFLINE=1 and PYTORCH_ENABLE_MPS_FALLBACK=1. The API keeps
running-processor ownership to prevent a second competing model run in
the same server instance. Completed receipts remain readable after
server restart.

## Timing and voice quality

Audio is not a valid Russian translation merely because the provider
completed or produced a WAV file. Each candidate retains separate
flags for source slot timing, semantic translation, native Russian
accent, speaker similarity and protected singing.

A **TIMING_CANDIDATE_ONLY** result may yield an MP4 preview for listening,
NOT an approved production segment. A failed timing gate retains its
raw WAV for investigation but has no automatically generated MP4.

Prior six-segment real benchmark: 3/6 timing candidates, 2/6 source-slot
overruns and 1/6 extreme hallucination (1.08s EN -> 33.06s RU), which
is blocked from placement by the timing gate. The native Russian and
voiceprint tests are independent pending work.

Seed-VC voice transfer remains a separate GPLv3 research candidate,
not shipped in the app nor silently injected into this lab provider.

## Not yet product-certified

The lab does not perform automatic source singing classification, so the
user must decide which intervals are speech. It currently handles
research previews, not automatic replacement of Qwen audio, entire
multi-hour Overdub export or independent Voice-ID/word-alignment QA.
It is not validated for Windows MPS, mobile, or 2-6 hour workloads.
The S2ST model weights are non-commercial and remain outside the app.

No GitHub Actions or external download/upload pipeline is added.

Screenshots, actual private source recordings and model checkpoints
remain local to the Mac and outside Git.

## Explicitly incomplete features

Research run cancellation, UI resume of partial model batches, native
app one-click model installation, automatic singing gold labels and
using approved S2ST segments in the full-length production dub are
separate future work. German and Spanish-source S2ST quality have
not been independently measured in this UI acceptance pass.
